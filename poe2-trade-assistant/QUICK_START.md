# 🚀 Быстрый старт PoE2 Trade Assistant

## ⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ
**Этот проект создан исключительно в образовательных целях!**
Автоматическая торговля может нарушать правила игры Path of Exile 2.

## 🎯 Варианты запуска

### 1. 🎪 Демо версия (РАБОТАЕТ ВСЕГДА)
```cmd
python demo.py
```
**Показывает все возможности без установки зависимостей**

### 2. 🖥️ Простой GUI (только tkinter)
```cmd
python gui_simple.py
```
**Графический интерфейс с демо данными**

### 3. 🔧 Автономная версия
```cmd
python run_standalone.py
```
**Полный функционал без сложных зависимостей**

### 4. 🌐 Полная версия с API
```cmd
# Сначала установите зависимости:
python -m pip install requests "pydantic>=2.5.0" pydantic-settings typer rich

# Затем запустите:
python run.py gui
```

## 📋 Что попробовать

### В демо версии:
- Посмотрите анализ цен
- Изучите систему фильтрации
- Проверьте рекомендации советника

### В GUI версиях:
- Поиск: `Chaos Orb`, `Divine Orb`, `Ring`, `Sword`
- Фильтры: "Только уникальные", "Дешевые"
- Двойной клик по предмету для анализа

## 🔧 Если есть проблемы

### Python не найден:
1. Скачайте с [python.org](https://python.org)
2. При установке поставьте галочку "Add to PATH"

### Модули не найдены:
```cmd
# Попробуйте по одному:
python -m pip install requests
python -m pip install pydantic
python -m pip install pydantic-settings
```

### tkinter недоступен:
- Используйте `python demo.py` - работает в консоли

### Ничего не работает:
- Запустите `python demo.py` - всегда работает!
