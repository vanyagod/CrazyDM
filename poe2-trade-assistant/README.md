# ⚔️ PoE2 Trade Assistant

Образовательный проект для анализа торговых данных Path of Exile 2 и помощи в принятии решений по покупке предметов.

## ⚠️ Важное предупреждение

**Этот проект создан исключительно в образовательных целях.** Автоматическая торговля и использование ботов может нарушать правила игры Path of Exile 2. Пожалуйста, соблюдайте условия использования игры.

## 🚀 Быстрый старт

### Демонстрация (без установки зависимостей)

```bash
python3 demo.py
```

### Полная версия

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Настройка
cp .env.example .env
# Отредактируйте .env файл

# 3. Запуск GUI
python run.py gui

# 4. Или командная строка
python run.py search "Unique Sword" --league Hardcore --max-price 50
```

## 🎯 Возможности

- 📊 **Анализ цен** - статистический анализ рыночных цен
- 🔍 **Поиск предметов** - мощная система поиска с фильтрами
- 📈 **Анализ трендов** - отслеживание изменений цен
- ⚡ **Уведомления** - мгновенные уведомления о выгодных предложениях
- 🎯 **Система фильтров** - гибкая настройка критериев поиска
- 🤖 **Советник по покупкам** - ИИ-помощник для принятия решений
- 🏗️ **Шаблоны билдов** - предустановленные фильтры для популярных билдов
- 📱 **GUI и CLI** - удобный графический интерфейс и командная строка

## 🎮 Примеры использования

### Поиск выгодных уникальных предметов
```bash
python run.py search --type unique --max-price 100 --league Hardcore
```

### Мониторинг конкретного билда
```bash
python run.py monitor --config-file config/witch_fire_build.json
```

### Анализ цен на валюту
```bash
python run.py analyze "Divine Orb" --days 7
```
