# Руководство по использованию PoE2 Trade Assistant

## ⚠️ Важное предупреждение

**Этот проект создан исключительно в образовательных целях.** Автоматическая торговля и использование ботов может нарушать правила игры Path of Exile 2. Пожалуйста, соблюдайте условия использования игры.

## Установка

### 1. Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### 2. Установка зависимостей

```bash
cd poe2-trade-assistant
pip install -r requirements.txt
```

### 3. Настройка

Скопируйте файл `.env.example` в `.env` и настройте параметры:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:

```bash
# Основные настройки
POE_API_BASE_URL=https://www.pathofexile.com/api/trade
REQUEST_DELAY=1.0
LEAGUE=Hardcore

# Уведомления
ENABLE_NOTIFICATIONS=true
DISCORD_WEBHOOK_URL=your_discord_webhook_url_here

# Фильтры по умолчанию
MAX_PRICE=100
MIN_PRICE=1
```

## Запуск

### Графический интерфейс

```bash
python run.py gui
```

или

```bash
python src/main.py gui
```

### Командная строка

#### Поиск предметов

```bash
python run.py search "Unique Sword" --league Hardcore --max-price 50
```

#### Мониторинг

```bash
python run.py monitor --config-file config/my_filters.json
```

#### Анализ цен

```bash
python run.py analyze "Divine Orb" --days 7
```

## Функции

### 1. Поиск предметов

- Поиск по названию, типу, ценовому диапазону
- Фильтрация по различным параметрам
- Сортировка результатов

### 2. Система фильтров

#### Создание фильтров

Фильтры можно создавать через GUI или JSON файлы:

```json
{
  "name": "Good Weapons",
  "description": "High-level weapons under 100 chaos",
  "conditions": [
    {
      "field": "item.ilvl",
      "operator": "gte",
      "value": 80
    },
    {
      "field": "price_chaos",
      "operator": "lte",
      "value": 100
    },
    {
      "field": "item.type_line",
      "operator": "regex",
      "value": "(Sword|Axe|Mace|Bow)"
    }
  ],
  "logic": "and",
  "enabled": true,
  "priority": 100
}
```

#### Операторы фильтров

- `eq` - равно
- `ne` - не равно
- `gt` - больше
- `gte` - больше или равно
- `lt` - меньше
- `lte` - меньше или равно
- `contains` - содержит
- `not_contains` - не содержит
- `regex` - регулярное выражение
- `in` - входит в список
- `not_in` - не входит в список

#### Предустановленные фильтры

- Выгодные предложения
- Уникальные предметы
- Высокий уровень предметов
- 6-связанные предметы
- Фильтры по типам (оружие, броня, украшения)

### 3. Анализ цен

- Статистический анализ цен
- Обнаружение выгодных предложений
- Выявление аномалий в ценах
- История цен

### 4. Уведомления

#### Типы уведомлений

- 🎯 Выгодные предложения
- 📉 Снижение цен
- 🆕 Новые объявления
- ✅ Завершение поиска
- ❌ Ошибки

#### Способы уведомлений

- Системные уведомления (Windows/Linux/macOS)
- Discord webhook
- Звуковые сигналы
- Уведомления в приложении

### 5. Советник по покупкам

Анализирует предметы и дает рекомендации:

- **BUY** - рекомендуется к покупке
- **WAIT** - стоит подождать лучшего предложения
- **SKIP** - не рекомендуется
- **INVESTIGATE** - требует дополнительной проверки

## Примеры использования

### Поиск выгодных уникальных предметов

1. Откройте GUI
2. Установите фильтр "Уникальные предметы"
3. Установите максимальную цену 50 chaos
4. Выберите лигу
5. Нажмите "Поиск"

### Мониторинг конкретного билда

1. Создайте фильтр для вашего билда:

```json
{
  "name": "Witch Fire Build",
  "conditions": [
    {
      "field": "item.type_line",
      "operator": "regex",
      "value": "(Staff|Wand|Robe)"
    },
    {
      "field": "item.explicit_mods",
      "operator": "regex",
      "value": "(Fire Damage|Spell Damage|Cast Speed)"
    },
    {
      "field": "price_chaos",
      "operator": "lte",
      "value": 80
    }
  ],
  "logic": "and"
}
```

2. Сохраните фильтр
3. Запустите мониторинг
4. Получайте уведомления о подходящих предметах

### Анализ рынка

```bash
# Анализ цен на Divine Orb за последние 3 дня
python run.py analyze "Divine Orb" --days 3

# Поиск всех уникальных мечей
python run.py search --type "Unique" --item-type "Sword"

# Экспорт результатов
python run.py search "Chaos Orb" --export results.json
```

## Решение проблем

### Ошибка подключения к API

1. Проверьте интернет-соединение
2. Убедитесь, что API Path of Exile доступен
3. Проверьте настройки `REQUEST_DELAY` - возможно, нужно увеличить

### Не работают уведомления

1. Проверьте `ENABLE_NOTIFICATIONS=true` в `.env`
2. Для Discord webhook проверьте правильность URL
3. Для системных уведомлений проверьте права приложения

### Медленный поиск

1. Увеличьте `REQUEST_DELAY` в настройках
2. Уменьшите количество одновременных запросов
3. Используйте более специфичные фильтры

### Неточные цены

1. Цены берутся с официальной торговой площадки
2. Конвертация валют приблизительная
3. Используйте фильтры по конкретной валюте для точности

## Безопасность

- **НЕ** используйте для автоматической торговли
- **НЕ** нарушайте правила игры
- Соблюдайте лимиты API
- Используйте разумные задержки между запросами

3. Проверьте настройки в `.env` файле
